4 ÉNIGMES

Quatre coffres verrouillés se dressent entre toi et le trésor. Chacun cache une clé. Décrypte, inspecte, réfléchis. À toi de jouer, hacker.

0 / 4 coffres ouverts
01

Le message intercepté

Base64

Nos radios ont capté une transmission ennemie. Elle semble encodée, pas chiffrée... Un format bien connu qui se termine souvent par =. Décode-la pour obtenir la première clé. 

c2VjcmV0
Besoin d'un coup de main ?

C'est de l'encodage Base64. Essaie dans un terminal : echo c2VjcmV0 | base64 -d, ou un décodeur en ligne.

02

Le parchemin de César

Chiffre de César

Un vieux parchemin, chaque lettre décalée de 13 rangs dans l'alphabet. Jules César adorait ça. Ramène chaque lettre à sa place pour lire le mot. 

cvengr
Besoin d'un coup de main ?

C'est un ROT13 (César, décalage de 13). A↔N, B↔O... Décale chaque lettre de 13. Astuce : echo cvengr | tr 'A-Za-z' 'N-ZA-Mn-za-m'

03

Le trésor invisible

Inspection

Certains secrets ne s'affichent pas... mais ils sont là, sous tes yeux. Un vrai hacker regarde toujours ce qui se cache derrière la page. Un indice est dissimulé quelque part dans le code de ce site.

Besoin d'un coup de main ?

Fais Ctrl+U (afficher le code source) ou clic droit → « Inspecter ». Cherche un commentaire HTML <!-- ... --> ou un élément caché. Le mot t'attend tout en haut du code.

04

La carte gravée

Hexadécimal

Le dernier coffre est verrouillé par une suite de nombres en base 16. Chaque paire de caractères représente un octet, donc une lettre. Convertis l'hexadécimal en texte pour obtenir la clé finale. 

6c 65 67 65 6e 64 65
Besoin d'un coup de main ?

Chaque paire hexa = un caractère ASCII. 6c = « l », etc. Essaie : echo 6c6567656e6465 | xxd -r -p
